# Revenge Classic Translator

Target: Revenge `1b1d297-main` / Discord Android `348.10 (348010)`.

**Status: development prototype, NOT installable.** A translation engine and viewport translation queue exist in the local v0.2 source archive, but the Discord 348.10 message renderer hook and Revenge Classic plugin packaging are not implemented or verified. No valid installation URL exists yet.

Planned: translate already-loaded, newly received and scrolled-in messages; English to Japanese; cache and show original; opt-in for DMs/private channels.

Translation provider candidate: MyMemory public API (free limits; messages are sent to a third party).

Do not paste the GitHub repository URL into Revenge Plugins `+`.
